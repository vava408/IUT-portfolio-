Socket

Application de chat en temps réel utilisant des sockets.

Description

Ce projet implémente une application de chat en temps réel utilisant des sockets. Les utilisateurs peuvent se connecter, envoyer des messages et interagir en temps réel.

Fonctionnalités

  • Envoi et réception de messages en temps réel
  • Gestion de plusieurs utilisateurs
  • Système de connexion des administrateurs : Authentification sécurisée pour les administrateurs.

Technologies utilisées

  • JAVA
